Adds functionality for pipe mods such as DBH to pipe into additional MO and MO mod buildings. Connecting to the DBH water network is kind of a pain in the butt so many mod authors don't bother, especially since it can't be done purely though XML.

Besides DBH and MO, any other mod's content will be patched only if you use the mod, so no requirements there.

I plan on adding more things to this as I come across buildings that are annoying to manually fill. I do *not* plan on implementing a medieval tier hot water heater through this mod.

Feel free to suggest other buildings to connect!

Currently supports:

Medieval Overhaul

    Ice Block Molds


DBH for Medieval

    Boiler Pot
